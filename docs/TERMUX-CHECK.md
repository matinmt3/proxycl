# بررسی نسخهٔ ۳.۳ روی گوشی در Termux

این راهنما برای آزمون واقعی گوشی است. تست‌های رایانه و فرمان `selftest` به‌تنهایی عملکرد تلگرام، بازشدن مرورگر اندروید یا ادامهٔ اسکن پس از بسته‌شدن Termux را تأیید نمی‌کنند. برای هیچ‌کدام از مراحل زیر ورود حساب تلگرام لازم نیست.

## نصب نسخهٔ آزمایشی در پوشهٔ جدا

فرمان زیر بعد از انتشار شاخهٔ `codex/telegram-v3-3` قابل استفاده است. نسخهٔ قبلی در `~/Revmamad` حفظ می‌شود و نسخهٔ آزمایشی در پوشهٔ دیگری نصب می‌شود:

```bash
pkg install -y curl
REVMAMAD_BRANCH=codex/telegram-v3-3 \
REVMAMAD_DIR="$HOME/Revmamad-v3.3-check" \
bash <(curl -fsSL https://raw.githubusercontent.com/matinmt3/proxycl/codex/telegram-v3-3/install.sh)
```

پس از بازشدن منو، گزینهٔ **۶** را برای خروج بزنید. سپس:

```bash
cd "$HOME/Revmamad-v3.3-check"
python main.py --version
python main.py selftest --network phone-check
cat output/networks/phone-check/selftest-report.json
```

باید نسخهٔ `3.3.0` و نتیجهٔ PASS برای وابستگی‌ها، تنظیمات، رمزنگاری، خواندن لینک، ذخیره/بازیابی و داشبورد محلی دیده شود. `all_passed: true` فقط آزمون آفلاین و ارتباط محلی را تأیید می‌کند. اگر وابستگی کم باشد، فرمان نصب `requirements-lite.txt` نمایش داده می‌شود؛ پس از رفع خطا دوباره `selftest` را اجرا کنید.

## اسکن واقعی، توقف و ادامه

نام `phone-check` یک برچسب محلی انتخابی است؛ برنامه نوع سیم‌کارت یا وای‌فای را خودکار تشخیص نمی‌دهد. برای اینترنت‌های متفاوت نام‌های جدا مانند `wifi` و `mobile` انتخاب کنید و همان نام را در فرمان‌های بعدی تکرار کنید.

```bash
python main.py best10 --mode mtproto --count 25 --network phone-check
```

مراحل `PREFILTER`، `BASELINE` و `FINALISTS` را بررسی کنید. تست طولانی‌تر برترین نامزدها می‌تواند چند دقیقه زمان ببرد. کمتر از ده نتیجه یا حتی صفر نتیجه، وقتی پروکسی‌های این اینترنت معیارها را پاس نکرده‌اند، خروجی معتبر است.

وقتی اسکن هنوز در حال اجراست، یک بار **Ctrl+C** بزنید و منتظر ذخیرهٔ نتایج بمانید. نتیجهٔ نیمه‌کاره باید برچسب **PROVISIONAL** داشته باشد. سپس بدون تغییر تنظیمات و بدون `--count` ادامه دهید:

```bash
python main.py best10 --mode mtproto --resume --network phone-check
```

ادامه باید از نامزدها و نمونه‌های ذخیره‌شده استفاده کند. اگر اجرای قبلی کامل شده، تنظیمات عوض شده یا شواهد قدیمی‌تر از مهلت پیش‌فرض ۳۰ دقیقه باشند، ردشدن Resume طبیعی است؛ یک اسکن تازه اجرا کنید. این مهلت شامل زمان آغاز و قدیمی‌ترین شواهد هم می‌شود. توقف اجباری برنامه ممکن است آخرین دستهٔ ذخیره‌نشده را از دست بدهد؛ Ctrl+C ذخیرهٔ نهایی را درخواست می‌کند.

برای بررسی دو حالت دیگر هم می‌توانید جداگانه اجرا کنید:

```bash
python main.py best10 --mode telegram --count 25 --network phone-check
python main.py best10 --mode web --count 25 --network phone-check
```

حالت `telegram` لینک واقعی `https://t.me/proxy` می‌دهد و همان آزمون MTProto را دارد. حالت `web` مخصوص HTTP/SOCKS است و با لینک تلگرام یکی نیست. هر حالت پوشه و checkpoint جدا دارد.

## اتصال، داشبورد و تاریخچه

اگر نتیجهٔ واجد شرایط وجود داشت، لینک نخست را در تلگرام باز و عملکرد واقعی آن را روی همین اینترنت بررسی کنید. نتیجهٔ پینگ رمزنگاری‌شده، سرعت دانلود مدیا یا عملکرد آینده را تضمین نمی‌کند.

```bash
python main.py dashboard --network phone-check
```

بررسی کنید مرورگر اندروید باز می‌شود یا نه. اگر خودکار باز نشد، آدرس چاپ‌شده، معمولاً `http://127.0.0.1:8000`، را دستی در مرورگر وارد کنید و این دو نتیجه را جدا گزارش کنید: «بازشدن خودکار» و «بازشدن دستی». این آزمون را `selftest` انجام نمی‌دهد. برای مشاهدهٔ پیشرفت هم‌زمان، سرور داشبورد را در یک نشست Termux و اسکن را در نشست دیگر اجرا کنید. با Ctrl+C سرور را متوقف کنید.

تب‌ها، فیلترها، کپی لینک، شمارنده‌ها، برچسب موقت و تاریخچه را بررسی کنید. داشبورد فقط اطلاعات می‌خواند و فرمان قابل کپی می‌دهد؛ توقف و ادامهٔ اسکن از ترمینال انجام می‌شود.

```bash
python main.py history 10 --mode mtproto --network phone-check
python main.py recheck --mode mtproto --network phone-check
```

تاریخچه باید مشاهدات همین برچسب/حالت را نشان دهد. `recheck` حداکثر بیست اتصال ذخیره‌شدهٔ واجد شرایط را دوباره با تست تازه بررسی می‌کند؛ اگر نتیجهٔ واجد شرایط ذخیره نشده باشد، پیام درخواست اسکن تازه درست است.

## چه چیزی گزارش شود؟

متن نسخهٔ برنامه، نسخهٔ اندروید، منبع نصب Termux، نام نوع اینترنت، نتیجهٔ `selftest` و مرحلهٔ بروز خطا را بفرستید. برای Resume بگویید Ctrl+C در کدام مرحله زده شد و ادامه از کجا شروع شد؛ برای داشبورد نتیجهٔ بازشدن خودکار/دستی را جدا بنویسید. اگر پروکسی بالای فهرست در تلگرام خوب نبود، زمان تست و رفتار مشاهده‌شده را ذکر کنید. رمز، کد ورود، توکن یا فایل نشست حساب را ارسال نکنید.

این گزارش باید پس از اجرای واقعی ثبت شود؛ وجود این راهنما به معنی قبولی آزمون گوشی نیست. پس از انتشار نهایی، فرمان معمول نصب از شاخهٔ `main` در README برای نصب/آپدیت عمومی استفاده می‌شود.
