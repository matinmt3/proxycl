# راهنمای نسخهٔ ۴ آزمایشی

REVMAMAD روی همان دستگاه و شبکهٔ انتخابی شما اندازه‌گیری می‌کند. آزمون عادی به حساب تلگرام نیاز ندارد. بهترین نتیجهٔ یک نمونه تضمین سرعت دانلود، دوام یا دسترسی آینده نیست.

## استفادهٔ روزمره

```bash
python launcher.py
python main.py best10 --mode mtproto --count ALL --network mobile
python main.py best10 --mode webproxy --minutes 10 --network mobile
python main.py best10 --mode web --count 100 --network wifi
python main.py best10 --mode mtproto --resume --network mobile
python main.py dashboard --no-browser --network mobile
python main.py doctor --network mobile
```

داشبورد سه گروه MTProto، Telegram WEB و HTTP/SOCKS دارد. قالب `t.me/proxy` در همان گروه MTProto انتخاب می‌شود. نام‌های قدیمی `telegram` و `web` در فرمان‌ها حفظ شده‌اند. نام شبکه را خودتان وارد می‌کنید؛ تشخیص خودکار اپراتور انجام نمی‌شود.

ALL همهٔ نامزدهای جمع‌آوری‌شده را انتخاب می‌کند. تعداد دلخواه تعداد نامزد است، نه تعداد موفقیت تضمینی. Ctrl+C یا «توقف و ذخیره» نتایج واجد شرایط تا آن لحظه را حفظ می‌کند؛ نتایج توقف زودهنگام با برچسب موقت نمایش داده می‌شوند. حداکثر ده نتیجه پیشنهاد می‌شود و ممکن است کمتر از ده نتیجه بگذرد.

شواهد از قدیمی‌ترین نمونهٔ استفاده‌شده، به‌طور پیش‌فرض پس از ۳۰ دقیقه منقضی می‌شوند. سابقه و علاقه‌مندی امتیاز تازه تولید نمی‌کنند. لینک منقضی یا فاقد اثبات معتبر در داشبورد فعال نمی‌شود. قفل سیستم‌عامل مانع نوشتن هم‌زمان CLI، داشبورد و زمان‌بند روی یک پوشهٔ خروجی می‌شود؛ پس از توقف اجباری فرایند، قفل آزاد و ادامه از آخرین checkpoint ممکن می‌شود.

## منابع و تنظیمات شخصی

```bash
python main.py sources --action list --mode mtproto
python main.py sources --action add --mode mtproto --name my-feed --url https://example.org/list.txt
python main.py sources --action manual --mode mtproto --file my-links.txt
python main.py sources --action export --file my-sources.json
python main.py sources --action import --file my-sources.json
python main.py sources --action disable --source-id ID
python main.py sources --action enable --source-id ID
python main.py settings --action save --network mobile
```

نشانی مثال منبع واقعی نیست. منابع را از انتشار واقعی وارد کنید. داشبورد نیز افزودن، واردکردن لینک، غیرفعال‌سازی، خروجی و بازیابی منابع را دارد. اطلاعات شخصی در `.revmamad/user-data/` قرار می‌گیرد؛ `--data-dir PATH` آن را جدا می‌کند. تنظیمات ذخیره‌شده در `settings.yaml` همان پوشه بارگذاری می‌شوند. واردکردن فایل منابع جایگزین منابع شخصی فعلی می‌شود و پیش از آن نسخهٔ پشتیبان ایجاد می‌شود. خروجی عمدی منابع شامل نشانی‌ها و لینک‌های شخصی است؛ گزارش عیب‌یابی آن‌ها را ندارد.

همهٔ عضویت‌های منبع یک پروکسی ثبت می‌شوند. منابع هم‌محتوا و حساب انتشار شناخته‌شده جدا گزارش می‌شوند؛ چند آینه به معنای چند ناشر مستقل یا چند تأیید نیست. ناشر نامشخص نیز صریحاً نامشخص می‌ماند. تعداد منابع قابل‌دریافت با تعداد پروکسی سالم متفاوت است.

## آزمون اختیاری مدیا

```bash
python -m pip install -r requirements-media.txt
python main.py media-test --mode mtproto --network mobile --link https://t.me/PUBLIC_CHANNEL/MESSAGE_ID
```

ابتدا یک اسکن کامل و تازه انجام دهید. وابستگی حساب جدا و روی Telethon 1.45.0 تثبیت شده است. مشخصات API متعلق به خودتان، شماره، کد ورود و رمز دومرحله‌ای فقط در ترمینال و بدون نمایش دریافت می‌شوند؛ آن‌ها را در فرمان، چت یا داشبورد قرار ندهید. نشست در حافظه است؛ فایل نشست یا فایل دانلود ایجاد نمی‌شود.

فقط لینک یک پیام عمومی دارای فایل/document پذیرفته می‌شود. عضویت خودکار، خواندن فهرست گفتگوها و ارسال پیام وجود ندارد. حداکثر پنج پروکسی تازه‌تأییدشده، تک‌به‌تک، هرکدام دو دور از همان بخش ابتدایی فایل (حداکثر ۸ MiB) آزمایش می‌شوند. زمان اندازه‌گیری حداکثر ده دقیقه است؛ زمان تایپ ورود جداست و درخواست‌های ورود مهلت محدود دارند. سقف پیش‌فرض دادهٔ قابل‌اندازه‌گیری ۱۰۰ MiB است و `--budget-mib` فقط آن را کاهش می‌دهد. حجم فایل با حجم مشاهده‌شدهٔ انتقال متفاوت است؛ سربار TLS، TCP و حامل WEB بیرون از این شمارش ممکن است وجود داشته باشد.

اتصال اصلی، دیتاسنتر مدیا و اتصال مجدد به همان پروکسی مقید هستند. CDN در این نسخه با `cdn_unsupported` متوقف می‌شود. دانلود کوتاه برچسب اطمینان محدود دارد. حساب محدودشده، فایل حذف‌شده و سقف مصرف، خرابی پروکسی محسوب نمی‌شوند. نتیجهٔ مدیا در `media-report.json` مستقل ذخیره می‌شود؛ داشبورد فقط نتیجهٔ همان شبکه و تطبیق شناسه با نتیجهٔ موجود را می‌بیند. ترتیب: تکمیل هر دو دور، توقف کمتر، سرعت میانهٔ بیشتر، سپس زمان اولین بایت کمتر. رتبهٔ پروتکل تغییر نمی‌کند.

در پایان خروج از نشست از سرور درخواست می‌شود. `confirmed` موفقیت تأییدشده و `not_confirmed` یعنی خروج از سرور تأیید نشده؛ مثلاً مسیر قطع شده یا سقف مصرف اجازهٔ ارتباط نداده است. در این حالت نشست را از بخش Devices تلگرام خودتان خاتمه دهید. دادهٔ محلی نشست روی دیسک ذخیره نشده است.

## رتبه‌بندی آزمایشی و WEB

```bash
python main.py best10 --mode mtproto --network mobile --ranking-policy v2-experimental
python main.py calibration --help
```

سیاست پیش‌فرض `v1` است. سیاست جدید، دورهای نهایی را با seed ثبت‌شده درهم می‌آمیزد و نوسان داخل اتصال را از تغییر بین اتصال‌ها جدا می‌کند. تغییر پیش‌فرض تنها پس از حداقل ۱۸ مقایسهٔ همتا، سه روز، دو شبکه و بازآزمایی مستقل پس از ۵ و ۳۰ دقیقه مجاز است. ابزار calibration شواهد ناقص یا تکراری را قبول نمی‌کند و خودش سیاست پیش‌فرض را تغییر نمی‌دهد.

Telegram WEB همچنان آزمایشی است. چهار حامل رسمی و TLS معتبر در محیط کنترل‌شده آزموده می‌شوند؛ پاسخ سایت یا موفقیت WebSocket به‌تنهایی قبولی تلگرام نیست. جدول کلاینت‌های واقعاً آزموده‌شده در [سند WEB](TELEGRAM-WEB.md) است؛ آزمون relay محلی معادل کلاینت واقعی روی گوشی نیست.

## آپدیت و بازگشت

```bash
python main.py update --check
python main.py update
python main.py update --rollback
```

آپدیت به Git checkout ریشه‌ای، شاخهٔ معتبر و فایل‌های tracked بدون تغییر نیاز دارد. ابتدا نسخهٔ جدید در محل موقت و runtime جدا نصب و selftest می‌شود، سپس شاخه fast-forward می‌شود. تنظیمات، منابع، خروجی و runtime قبلی حفظ می‌شوند. شکست آماده‌سازی نسخهٔ اجرایی قبلی را نگه می‌دارد؛ وضعیت apply نیمه‌تمام تا بازگشت مسدود می‌شود. بازگشت تنها برای آخرین آپدیت ثبت‌شده و HEAD مورد انتظار مجاز است؛ فایل شخصی یا ویرایش tracked بازنویسی نمی‌شود. محیط Python سیستم و بسته‌های Termux از داخل آپدیت ارتقا داده نمی‌شوند.

برای نسخهٔ آزمایشی از پوشهٔ جدا استفاده کنید. ZIP سورس فاقد Git، فرمان آپدیت ندارد؛ برای آپدیت از clone نصب کنید. ساختار قدیمی دارای زیرپوشهٔ `TelegramProxySelector` به نصب جدا نیاز دارد. پیش از جابه‌جایی دستی داده‌ها نسخهٔ پشتیبان بگیرید. دادهٔ ۳.۴ خواندنی می‌ماند؛ فقدان متادیتای تازه به‌طور خودکار به تأیید تازه تبدیل نمی‌شود.

## عیب‌یابی و معیار پایداری

گزارش `doctor` فقط فهرست مجاز نسخه‌های وابستگی، وضعیت محلی و شمارنده‌هاست؛ شماره، کد، رمز، کلید نشست، توکن کنترل و نشانی خصوصی منابع در آن قرار نمی‌گیرد. این فرمان تست زندهٔ تلگرام نیست.

برای ارتقا به نسخهٔ پایدار، checklist گوشی واقعی، انتقال حساب واقعی، مقایسه‌های چندروزه و کلاینت WEB باید تکمیل شوند. وضعیت دقیق در [RELEASE-GATES.json](RELEASE-GATES.json) ثبت می‌شود. تعداد تست خودکار جایگزین این معیارها نیست.
